# Anatomia Drag & Drop

PWA responsivo com duas imagens:

- Imagem A: Plexo braquial e axila
- Imagem B: Antebraço e palma

## Como subir no GitHub Pages

1. Extraia o ZIP.
2. Suba todos os arquivos para a raiz do repositório.
3. Vá em Settings > Pages.
4. Source: Deploy from a branch.
5. Branch: main / root.
6. Save.
